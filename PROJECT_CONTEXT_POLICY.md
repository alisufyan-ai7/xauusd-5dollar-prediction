# PROJECT_CONTEXT_POLICY

## Clean-room scope

This repository is a new, isolated research project for studying whether XAU/USD contains identifiable market states in which a USD 5 directional target can be predicted before a defined adverse excursion within a fixed horizon.

## Allowed context

Only the following sources are admissible for this project:

1. The current ChatGPT conversation in which this repository was created and initialized.
2. This repository (`alisufyan-ai7/xauusd-5dollar-prediction`) and its branches, commits, pull requests, issues, Actions runs, and artifacts.
3. Fresh public research and public datasets deliberately obtained for this project.
4. Exness information supplied in this project conversation or freshly verified from public Exness documentation for this project.

## Forbidden context

Do not use, import, derive from, or rely on:

1. Account-level memory or saved memory.
2. Other ChatGPT conversations or projects.
3. Any other GitHub repository.
4. Any previous XAU/USD research, EA, model, experiment, strategy, dataset, code, result, conclusion, threshold, or configuration outside this repository and this conversation.
5. Quarantined or copied artifacts from unrelated work.

## Public research rule

Fresh public information may be researched when necessary. Every material public source used for research decisions should be documented in this repository with source, access date, purpose, and relevant licensing/usage constraints where applicable.

## Reproducibility rule

Research inputs, transformations, configurations, preregistrations, code versions, and result summaries should be version-controlled or cryptographically identified wherever practical.

## Trading safety rule

Research and historical testing come first. No live-money execution should be enabled merely because code is operational. Progression should be:

1. data validation;
2. labeling and baselines;
3. model research;
4. chronological validation;
5. sealed out-of-sample testing;
6. forward shadow/demo testing;
7. execution validation;
8. live capability only after separate evidence-based approval.

## Project origin

This repository begins from a clean state. No prior repository is an ancestor or admissible source.
